# GW-LINK L510 固件更新

GW-LINK L510（MediaTek MT7986A、2 GiB RAM、128 GB eMMC）的公开固件发布与 OTA 更新渠道。

**[下载正式版](https://github.com/hongheshan-svg/gw-link-l510-firmware/releases/latest)**

最新版本 **20261108.1-setup** 新增首次登录快速安装向导：设置管理员密码、自动获取 IP／宽带拨号／静态 IP，以及双频同名 Wi-Fi。沿用深色青绿控制台与手机布局。已经设置管理员密码的设备保留配置升级后不强制重新设置；也可从“系统 → 快速设置”进入。

## 升级

选择 `gw-link-l510-…-sysupgrade.bin`，先备份配置，再从路由器后台“系统 → 备份与更新”上传。

从 **20261101.3** 起，可在左上角品牌下方的版本按钮中检查新版本、下载校验并确认安装。后台只自动检查，不自动安装；安装保留标准备份范围内的配置并重启，独立 `/srv` 数据分区不格式化。请保持供电。

**20261101.2 及更早版本需要手动升级一次**：这些版本携带的旧签名公钥已停用，不能校验新版本签名。

## OTA 校验

`ota.json` 和 `ota.json.sig` 是签名更新清单；仅正式 Latest 版本用于在线更新。

当前公钥指纹：**`f9b9efb27df7e18a`**，从 20261101.3 起使用。仓库中的 `release.pub` 与固件内置公钥一致。旧指纹 `6247692bc85368ec` 已停用。

路由器校验签名、SHA256、文件大小、设备型号、平台和版本，并执行标准 sysupgrade 兼容性检查。不需要 GitHub 令牌；下载需能访问 GitHub 及 Releases 资产域名，系统时间需正确。

本设备未配置 A/B 固件自动回滚。向导的网络设置回退只适用于配置应用，不代表刷机失败后能自动恢复固件。发布使用固定环境编译及隔离测试；实机刷写、无线射频与拨号仍需实机验收。

## 源码和许可

基于 [OpenWrt](https://github.com/openwrt/openwrt) 25.12.6，使用发布附件中的固定 feeds 和本地补丁构建。

每个正式版本附带构建配置、源代码版本、定制源码与验证报告；20261108.1 起另外提供对应提交的完整主仓库源码压缩包。结合公开上游及固定 feeds 可复现构建。遵循 OpenWrt 及各软件包各自的许可证。

此仓库作为公开固件及对应构建资料的发布渠道，固件和源码不包含发布签名私钥或 GitHub 访问令牌。

新安装默认双频 SSID 为 `GW-LINK`，无线密码为 `12345677`。首次进入后台请通过快速安装向导设置管理员密码并修改无线密码。
